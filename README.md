# Youngbin Kim · Minimal Academic Homepage

간결한 연구자 개인 홈페이지입니다. 예시로 제시된 학술 홈페이지의 구성처럼 프로필, 연구 관심 분야, 최근 소식, 논문, 프로젝트, 학력/경력을 한 페이지에 배치했습니다.

## GitHub Pages에 공개하는 방법

1. [GitHub](https://github.com/new)에서 `<사용자아이디>.github.io` 저장소를 생성합니다. GitHub Free 이용 시 `Public`으로 설정하세요.
2. 이 ZIP 파일을 해제한 뒤 **ZIP 안의 파일과 폴더 전체**를 해당 저장소의 최상위에 업로드합니다. ZIP 파일 자체를 업로드하지 마세요.
3. `index.html`, `style.css`, `assets/`가 저장소 최상위에 있는지 확인합니다.
4. `Settings → Pages → Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
5. 배포 완료 후 `https://<사용자아이디>.github.io/`를 확인합니다.

## 내용 수정하기

- 모든 프로필 및 연구 내용: `index.html`
- 색상, 간격, 모바일 레이아웃: `style.css`
- 프로필 사진: `assets/profile.webp`
- 논문 그림: `assets/scv.webp`, `assets/astra.webp`, `assets/party.webp`, `assets/domain.webp`
- CV 다운로드 파일: `assets/Youngbin_Kim_CV.pdf`

이 사이트는 별도의 빌드 도구나 JavaScript 프레임워크 없이 동작합니다. 수정 후 저장소에 파일을 다시 업로드하면 홈페이지가 자동으로 갱신됩니다.

## 공개 전 확인

사진, 소속, 기관 이메일, CV, 연구 그림이 포함되어 있습니다. 인터넷에 공개하기 전에 본인의 공개 동의 및 자료 사용 가능 범위를 확인하세요. 논문은 출판사의 DOI 또는 공개 프로젝트 페이지로 연결됩니다.
